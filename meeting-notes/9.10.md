### Short meeting agenda

**1. Confirm the project goal — 2 minutes**

Make sure everyone understands that ICE TRACK has four main areas:

- Order entry
- Inventory management
- Shipment tracking
- Trouble tickets

**2. Decide the initial scope — 5 minutes**

Choose which features must be included in the first working version. Start with a simple workflow:

* take inspiration from bakeshop.com

> Create customer → enter order → check inventory → record shipment → create trouble ticket if needed.

* Account creation -> login / signup (signup to onboarding flow) -> homepage -> options to order entry, inventory management, shipment tracking, troubleshooting tickets

**3. Discuss the tech stack — 4 minutes**

Ask:

- What languages or tools has everyone used? (needed to be asked again next meeting)
	- C/C++, Java, Python, HTML/CSS
	- 
- Is the project expected to be a desktop application or can it be web-based?
	- web based application
- Which database should the team use?
	- SQL based, Postgres? Supabase?
- Can every member install and run the chosen tools?
	- Conda
	- Veet / React, Javascript/Typescript


**4. Assign immediate tasks — 5 minutes**

- Draft the main screens.
- Identify database entities.
- Compare two possible tech stacks.
- Break the requirements into must-have and optional features.
- Develop the initial test plan.

**5. Confirm deadlines — 2 minutes**

Before ending, record:

- Who owns each task
- When each task is due
- Where files and code will be stored
	- GitHub, local cloning
